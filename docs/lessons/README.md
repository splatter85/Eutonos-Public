# Lessons Learned

Purpose: durable reusable knowledge for future work.

Use lessons files for findings that should change how future agents or developers work. Do not use them as a duplicate active task board; active work stays in `docs/CURRENT_TASK.md`.

## Routing

- `general.md`: cross-project or cross-runtime lessons.
- `experiments/`: experiment, proof-run, or spike lessons when the project has recurring experiments.
- App/project-local `LESSONS.md`: findings that mostly apply to one app or project area.
- Troubleshooting, bug, or helper docs: diagnosis paths that should prevent repeated investigation.

If a lesson changes workflow, architecture direction, current behavior, future scope, or troubleshooting policy, update the owning docs and add a milestone entry to `docs/DOC_CHANGE_LOG.md`.
