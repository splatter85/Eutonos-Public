# Project Goals

The universal starter kit packages ToVA Project Workflow generation 2 so long-running repositories can preserve project intent, current work, verification truth, parallel-edit boundaries, bugs, lessons, restart context, and bounded AI-to-AI or cross-machine transfers without depending on chat memory.

Success means installation discovers before writing, preserves project-owned bytes and casing, creates only missing owners, archives retired history inside the target, advertises only real commands, gives transfers a safe non-authoritative home, asks one short evidence-informed first-run conversation when project definition remains open, and withholds installation identity until acceptance. The package must remain useful without redefining the target product or requiring every optional overlay or module.

Non-goals are publishing without owner approval, replacing Git history, fabricating target-project truth from AI suggestions, enabling every module, or treating the workflow itself as the target product.
