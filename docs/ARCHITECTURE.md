# Architecture

`project-workflow/core/CORE.json` declares the versioned portable roles, including navigation-only repository indexes, Execution State, safe Development Nodes, Collaboration Protocol, Agent Notes, Exchange/receipt/context templates, conditional first-run project discovery, compatible existing-owner candidates, create-only templates, retired paths, and archive root. `tools/project-workflow-install.js` owns explicit-root discovery, non-authoritative role suggestions, nested-root exclusion, exact-plan bootstrap, ledger-gated retirement, and acceptance-gated finalize. `tools/project-workflow-migration-check.js` validates accepted reconciliation, extension, duplicate-role, and retirement preconditions without deciding project meaning. `tools/project-workflow-check.js` validates installed owners, actual casing, retired paths, content, commands, and modules. `tools/collaboration-workflow-check.js` validates repository routes, Action references, adaptive context selection, the durable/volatile execution split, one-writer lease, safe node metadata, Notes, and v1/v2 exact-revision Exchange integrity.

`tests/` and `test-fixtures/` prove focused behavior, adversarial zero-write boundaries, and F1-F7 disposable migrations including mature versioned, native, and nested-project cases. Temp installations and their manifests are generated evidence, not durable package source. `project-workflow/evidence/` and `project-workflow/releases/` contain accepted evidence, release-specific upgrade metadata, and RC records.

The root `.project/` and `docs/` describe this starter package itself. `.project/EXECUTION_STATE.json` is durable execution truth while pull-request checkpoints or ignored `.tova-runtime/` hold volatile Action state; `.project/ACTIVE_AGENT_WORK.md` is compatibility-only. `docs/REPOSITORY_INDEX.*` provides checked navigation to existing owners/source/tests/proof without owning their truth. `docs/TOVA_SETUP.md` is the conditional deployment-to-acceptance guide, `docs/TOVA_MIGRATION.md` owns established-repository/older-version reconciliation semantics, and `docs/PROJECT_DISCOVERY.md` is the narrower interview/writeback protocol; none replaces product truth. `project-workflow/modules/app-build-assurance/` is a disabled-by-default removable extension with its own schema, executable example, checker, and retirement boundary. `docs/handoffs/` owns generic packages and bounded execution Exchanges, while ZIPs and external copies remain transport artifacts rather than truth. `overlays/` contains optional guidance that extends but does not compete with universal owners. `archive/old-projects/` preserves retired generation 1 bytes. Git is the exact package history and rollback source. The deterministic Workflow Controller remains shelved future work.
