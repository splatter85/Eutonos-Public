# Integrations And Operations Overlay

Use this optional overlay when a target project needs generic connector inventory, error/logging policy, or development-expectation templates beyond the universal core.

Included files:

- `docs/CONNECTORS.md`
- `docs/DEVELOPMENT_INSTRUCTIONS.md`
- `docs/ERROR_HANDLING_AND_LOGGING.md`

Apply only the files justified by the target project's real integrations and operations. Replace template prompts with project truth, register real verification in the target Project Health owner, and keep production claims separate from local evidence. Removing this overlay must not remove universal core owners or project evidence distilled into them.
